# فوتسال (Salon) — نسخه اندروید Flutter

محل پروژه: `futsal-booking-system/android` (کنار فرانت‌اند اصلی React/Tauri — هویت بصری اپ با نسخه دسکتاپ یکسان است: گرادیان آبی `#2563EB` → بنفش `#7C3AED`).

مهاجرت کامل اپلیکیشن دسکتاپ **Tauri + React + TypeScript** به یک اپلیکیشن نیتیو اندروید با **Flutter + Dart + Material 3**.

> ⚠️ فرانت‌اند قدیمی (Tauri/React) دست‌نخورده باقی مانده است و این پروژه در پوشه `android` کنار آن قرار دارد.

## ✨ امکانات پیاده‌سازی‌شده

### احراز هویت
- ورود با شماره موبایل و رمز عبور (توکن JWT در حافظه امن دستگاه)
- ثبت‌نام سه‌مرحله‌ای (انتخاب نقش کاربر/مدیر سالن، سنجش قدرت رمز، پذیرش قوانین)
- بازیابی رمز عبور دومرحله‌ای با نمایش کد توسعه (dev_code)
- تایید ایمیل/شماره (شرط انجام رزرو)
- محافظت مسیرها (Route Guard) و خروج خودکار بعد از انقضای توکن (401)

### خانه و جستجو
- نمایش سالن‌های نزدیک (دسترسی موقعیت مکانی با fallback خاموش)
- محبوب‌ترین سالن‌ها بر اساس امتیاز
- «اخیراً دیده‌شده» (ذخیره محلی، حداکثر ۱۲ مورد)
- چیپ‌های ورزش (فوتسال، بدنسازی و...)
- نتایج زنده فوتبال از Varzesh3 (زنده / آینده / پایان)
- اخبار ورزشی از Varzesh3
- جستجو با debounce (۳۵۰ms)، تاریخچه جستجو (حداکثر ۸ مورد) و جستجوهای محبوب

### سالن‌ها و رزرو
- لیست سالن‌ها با سگمنت فوتسال/بدنسازی
- شیت فیلتر: نوع ورزش، بازه قیمت (Range Slider)، امکانات، فقط تاییدشده + چیپ‌های فیلتر فعال
- صفحه جزئیات سالن: گالری تصاویر، امکانات، اطلاعات تماس
- نوار انتخاب ۱۴ روز آینده (تاریخ شمسی با shamsi_date)
- لیست سانس‌ها با قیمت و وضعیت (آزاد / رزرو شده)
- ایجاد رزرو (Pending در Redis) و تایید/رد توسط مدیر سالن
- سالن‌های بدنسازی: نمایش و خرید پلن‌های اشتراک

### درگاه پرداخت (شبیه‌سازی‌شده)
- فاکتور خودکار برای رزرو تاییدشده
- فرم کارت بانکی: شماره کارت با فاصله‌گذاری خودکار هر ۴ رقم، CVV2، ماه/سال انقضا
- اعتبارسنجی کامل (۱۶ رقم کارت، CVV ۳-۴ رقمی، ماه ۱-۱۲، سال شمسی)
- صفحه موفقیت پرداخت + رسید پرداخت در جزئیات رزرو

### بازی‌های گروهی (Games)
- کشف بازی‌ها با فیلتر سطح مهارت، ظرفیت و ترتیب (۵ حالت)
- بازی‌های من + دعوت‌نامه‌های دریافتی (پذیرش/رد)
- صفحه جزئیات: بازیکنان، درخواست‌های عضویت (تایید/رد)، لیست انتظار
- ساخت بازی روی رزرو تاییدشده (تعداد بازیکن، سطح، دسترسی: خصوصی/عمومی/عمومی با تایید، نحوه پرداخت)
- لینک‌های دعوت: ساخت، اشتراک‌گذاری، غیرفعال‌سازی، بازتولید
- پیوستن با توکن دعوت (Deep link با scheme `salon://join`)
- پرداخت سهم هر بازیکن در حالت سهمی
- چرخه حیات بازی: شروع / پایان / لغو
- WebSocket زنده برای اعلان‌ها (reconnect با backoff نمایی)

### قراردادها و رقابت قیمت
- ایجاد قرارداد بلندمدت (روز هفته، ساعت، تکرار هفتگی/دوهفته‌ای/ماهانه، قیمت تخفیف‌دار)
- محاسبه تعداد جلسات دقیقاً مطابق الگوریتم بک‌اند (weekday پایتون)
- خلاصه مالی و جزئیات قرارداد
- رقابت قیمت برای مدیران: شروع رقابت روی سانس آزاد، نمایش بهترین پیشنهاد، توضیح قوانین ۲۴ ساعته

### داشبوردها
- داشبورد کاربر: آمار، دسترسی سریع، رزروهای پیش رو، اشتراک‌های فعال
- داشبورد مدیر سالن: انتخاب سالن، رزروهای در انتظار (تایید/رد)، رزروهای ۷ روز آینده، تولید سانس
- پنل ادمین: آمار کلی، مدیریت کاربران (تایید/رد مدیران)، تایید سالن‌های در انتظار

### پروفایل و اعلان‌ها
- ویرایش نام، تغییر رمز عبور، نمایش وضعیت تایید
- میان‌برهای نقش‌محور (مدیریت سالن / پنل ادمین / قراردادها / رقابت‌ها)
- اعلان‌ها: لیست با آیکون اختصاصی برای ۲۴ نوع اعلان، شمارنده خوانده‌نشده، علامت‌گذاری تکی و دسته‌جمعی، ناوبری به بازی مرتبط

### علاقه‌مندی‌ها
- ذخیره محلی (بدون نیاز به بک‌اند، مطابق نسخه وب) با toast بازخورد

## 🏗 معماری

```
lib/
├── main.dart                      # نقطه ورود، لود .env، override کردن KeyValueStore
├── app → (SalonApp در main)       # MaterialApp.router، تم روشن/تیره، RTL، fa_IR
├── core/
│   ├── config/app_config.dart     # آدرس API و دامنه تصاویر (از .env)
│   ├── constants/                 # ثابت‌ها (ماه‌های شمسی، روزها، امکانات)
│   ├── error/                     # ApiException + ErrorMapper (پیام‌های فارسی دوستانه)
│   ├── network/api_client.dart    # Dio + interceptor توکن + هندل 401 سراسری
│   ├── storage/key_value_store.dart  # SharedPreferences + flutter_secure_storage
│   ├── theme/app_theme.dart       # دیزاین‌سیستم کامل (رنگ، تایپوگرافی، کامپوننت‌های M3)
│   ├── utils/                     # فرمترهای فارسی (رقم/قیمت/تاریخ شمسی) + validatorها
│   └── widgets/                   # دکمه، فیلد، اسکلتون، EmptyState، ErrorState، StatusChip...
├── features/
│   ├── auth/          (domain, data, providers, pages)
│   ├── home/          (Varzesh3 + سالن‌های نزدیک)
│   ├── venues/        (لیست، جزئیات، فیلتر، نظرات، سانس‌ها)
│   ├── bookings/      (لیست، جزئیات، کنسل، رزروهای Pending)
│   ├── payments/      (درگاه کارت شبیه‌سازی‌شده)
│   ├── memberships/   (پلن‌ها و خرید اشتراک)
│   ├── contracts/     (قرارداد + countContractSessions)
│   ├── competitions/  (رقابت قیمت)
│   ├── games/         (بازی گروهی کامل)
│   ├── notifications/ (REST + WebSocket)
│   ├── reviews/       (CRUD نظر + خلاصه امتیاز)
│   ├── slots/         (مدل و سرویس سانس)
│   ├── search/        (جستجو + تاریخچه)
│   ├── favorites/     (ذخیره محلی)
│   ├── profile/       (ویرایش پروفایل و رمز)
│   ├── dashboard/     (کاربر + مدیر سالن)
│   ├── admin/         (داشبورد، کاربران، سالن‌ها)
│   └── uploads/       (آپلود تصویر)
└── router/
    ├── app_router.dart   # GoRouter + redirect نقش‌محور
    └── app_shell.dart    # NavigationBar پایین + زنگ اعلان‌ها
```

### تصمیم‌های کلیدی
| موضوع | انتخاب | دلیل |
|---|---|---|
| State Management | **Riverpod 2** | Notifierهای immutable، تزریق وابستگی، تست‌پذیری |
| ناوبری | **GoRouter** | Redirect نقش‌محور، Deep link، ShellRoute |
| شبکه | **Dio** | interceptor توکن، timeout، نگاشت خطا |
| تاریخ شمسی | **shamsi_date** | تبدیل دقیق جلالی (RTL درجه یک) |
| توکن | **flutter_secure_storage** | امن‌تر از SharedPreferences |
| اعلان زنده | **web_socket_channel** | معادل useWebSocket نسخه وب |
| موقعیت | **geolocator** | سالن‌های نزدیک با fallback |

### قراردادهای API
تمام endpointها، نام فیلدها (snake_case)، شکل خطاها (شامل `{"code","message"}` بازی‌ها) و رفتار Pending/Redis **عیناً مطابق بک‌اند FastAPI** حفظ شده‌اند.

## 🚀 اجرا و ساخت

### پیش‌نیازها
- Flutter SDK (stable)
- Android SDK + JDK 17
- بک‌اند FastAPI در حال اجرا

### تنظیم آدرس API
فایل `.env` در ریشه پروژه:

```env
API_BASE_URL=http://2.189.255.225/api/v1
STATIC_DOMAIN=http://2.189.255.225
```

### دستورات

```bash
flutter pub get          # نصب وابستگی‌ها
flutter analyze          # تحلیل ایستا (بدون خطا/هشدار)
flutter test             # ۲۷ تست (مدل‌ها، فرمترها، validatorها، قرارداد)
flutter run              # اجرا روی دستگاه/شبیه‌ساز
flutter build apk --release   # ساخت APK
```

### خروجی APK
```
android\build\app\outputs\flutter-apk\app-release.apk
```

> نکته: چون `dl.google.com` در این شبکه در دسترس نیست، مخازن Gradle به آینه **Aliyun** و بسته‌های SDK (platform-35 و NDK r27) به‌صورت دستی از آینه **Tencent** نصب شده‌اند. این تنظیمات در `android/settings.gradle.kts` و `android/build.gradle.kts` ثبت است.
