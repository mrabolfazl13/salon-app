# ⚽ فوتسال - سیستم رزرو سالن

## ✨ ویژگی‌ها

- 🎯 **رزرو آسان** - رزرو سالن در چند ثانیه
- 🏆 **رقابت قیمت** - بهترین قیمت را پیدا کنید
- 📄 **قرارداد بلندمدت** - برای تیم‌های حرفه‌ای
- 📱 **اپلیکیشن موبایل** - با Tauri برای Android و iOS
- 🌙 **حالت تاریک/روشن** - پشتیبانی از تم
- 🎨 **طراحی مدرن** - با Material-UI و Tailwind CSS
- ⚡ **انیمیشن‌های روان** - با Framer Motion

## 🚀 نصب و اجرا

### پیش‌نیازها
- Node.js 18+
- Rust (برای Tauri)
- Android Studio (برای خروجی Android)
