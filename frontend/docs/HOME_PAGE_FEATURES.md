# بخش‌های جدید صفحه اصلی - مستندات

## خلاصه تغییرات

این مستندات شامل تمام کامپوننت‌های جدیدی است که برای افزایش جذابیت و جذب کاربران به صفحه اصلی اضافه شده‌اند.

## لیست کامپوننت‌ها

### 1. HeroSection
**مسیر:** `src/components/home/HeroSection.tsx`

**هدف:** اولین چیزی که کاربر می‌بینه - نمایش قدرتمند برند و ارزش پیشنهادی

**ویژگی‌ها:**
- عنوان جذاب با گرادیان رنگی
- دکمه‌های CTA قوی (مشاهده زمین‌ها، ثبت‌نام رایگان)
- آمار اجتماعی (Social Proof): تعداد کاربران، زمین‌ها، مسابقات، امتیاز
- ویژگی‌های چرخشی خودکار (رزرو فوری، بهترین قیمت، تیم‌سازی آسان)
- انیمیشن‌های پس‌زمینه متحرک

---

### 2. WhyUsSection
**مسیر:** `src/components/home/WhyUsSection.tsx`

**هدف:** نمایش مزایای رقابتی سیستم

## نکات فنی

### وارد کردن کامپوننت‌ها
```typescript
import { HeroSection } from '@/components/home/HeroSection'
// یا استفاده از index
import { HeroSection, WhyUsSection } from '@/components/home'
```

### استایل‌ها
- تمام کامپوننت‌ها از MUI Box و Typography استفاده می‌کنند
- انیمیشن‌ها با Framer Motion
- آیکون‌ها از Iconify React
- طراحی کاملاً واکنش‌گرا با breakpointهای xs, sm, md, lg

### تم و رنگ‌ها
- استفاده از `gradients`, `radii`, `shadows` از `@/theme`
- رنگ‌های اصلی: #fbbf24 (طلایی), #3b82f6 (آبی), #10b981 (سبز)
- پشتیبانی از dark mode

### عملکرد
- Lazy loading با React.lazy قابل پیاده‌سازی است
- شمارنده‌ها فقط هنگام مشاهده انیمیشن دارند (useInView)
- همه تصاویر placeholder هستند و باید با داده واقعی جایگزین شوند
